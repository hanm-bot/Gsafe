## Giao việc

```
Khi nhận nhiệm vụ:
1. Kênh xuất bản nào?
   ├── Facebook cá nhân/Fanpage → gọi facebook.md
   ├── LinkedIn chuyên nghiệp   → gọi linkedin.md
   ├── Báo cáo trình Ban Giám Đốc/Sếp → gọi executive-summary.md
   ├── Bản tin Email / Substack → gọi newsletter.md
   ├── Blog / Website           → Giữ nguyên Markdown chuẩn
   └── Cần xuất bản Word/PDF/Slide → Bàn giao sang skill xuat-ban-cong-vu
```

## Hợp đồng bàn giao

- Nhận input từ: Ban Biên tập (`editorial/`) — bài viết đã chốt nội dung
- Giao output cho: Ban Kiểm duyệt (`review/`) — soát lỗi lần cuối
- Sau khi được duyệt: Chuyển giao sang `xuat-ban-cong-vu` nếu cần xuất file Word/PDF/Slide.
